# 企业元器件识别规则（识别时按相关度检索注入提示词；每行一条，# 开头为注释）
标准件代号必须按明细栏原文逐字符输出：深沟球轴承为 GB/T 276，六角头螺栓 C 级为 GB/T 5780，圆锥销为 GB/T 117，普通平键为 GB/T 1096，十字槽盘头螺钉为 GB/T 818，六角螺母 C 级为 GB/T 41，弹簧垫圈为 GB/T 93，骨架油封为 GB/T 13871.1。
明细栏"重量"列单位为克(g)，weight 字段输出纯数字不写单位；空缺填 null。
垫片类材料按明细栏原文输出（如"石棉纸"与"石棉板"是不同材料），不要自行归一化改名。
非发动机图纸（减速器、变速箱、泵、阀等）的 category 按通用机械分类：机体箱架类 / 传动件 / 轴系件 / 紧固件 / 密封件 / 润滑与附件 / 其他。
装配图明细栏中同一国标号下不同规格（如轴承 6204 与 6206）是不同零件行，不得合并。
