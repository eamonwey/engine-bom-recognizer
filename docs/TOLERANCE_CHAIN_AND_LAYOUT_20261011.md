本次交付覆盖先前授权的 ERR-01 一维公差累积功能，以及本轮反馈的“视图蓝框截断底部轮廓”。代码和验证产物已保存；正在运行的旧 Python 服务需正常重启后才会加载后端更改，旧任务结果不会自动重算。浏览器刷新后请重新上传识别。

## 1. 改了什么

### 公差链

1. 视觉模型独立读取尺寸原文、单位、原始页码、视图、装配分区、尺寸线端点、组成长度与功能要求。尺寸端点不是数字文字框，不能按数值反推位置。
2. 尺寸抽取进入有界 AgentLoop，最多三次。发现把“间隙 S 的要求”引用给“腔体 L”时要求重新读图；不由程序猜改角色。耗尽后标记 needs_review，不把未通过校验的尺寸送入计算；Web 结果保留抽取状态、错误和模型事件。
3. 有明确同一分区及功能封闭环时，程序建立端点图，寻找唯一连续路径。符号由路径行走方向决定。多路径、不相连或缺公差保留未知；禁止挑选数值恰好相等的路径。
4. 不具备足够端点图依据时，保留已有模型候选链及其校验流程。候选同样必须通过尺寸角色、页码、视图、方向、分区、连续性及原文公差校验。普通无公差的尺寸链保留原功能，与公差计算分开。
5. 用 Decimal 区间算术计算极值，并记录每个增减环贡献。已成功计算的公差结果不因无关普通尺寸链调用失败而丢失；自由视觉审图回复不能覆盖确定性计算数值。
6. 页面展示正常与异常链的计算依据。没有 ERR-01 问题也能看到已算出的范围，未知或提取失败不会显示为已通过。

对组成环 `[a,b]`：增环贡献 `[a,b]`，减环贡献 `[-b,-a]`。累加得到封闭环范围。比较允许区间后分为：完全在允许范围内、部分极限组合可能超差、两个区间不相交（全范围不满足）。恰好达到边界仍属于范围内，同时单独提示边界。

已支持：正负组成环、对称/非对称公差、明确极限尺寸、已知单位换算、负值或零中心功能间隙、水平及竖直一维链。组成实体长度仍必须为合理正值。

暂未支持：未注公差自动套标准、斜向/二维/三维链、形位公差耦合、统计/RSS、相关性、温度变形及选择装配。视图对应关系仍来自模型事实，需要对照原图复核。此阶段不能宣称全项 ERR-01 或生产验收已完成。

计算方法背景参考公开教学资料：[MIT Tolerance Design](https://ocw.mit.edu/courses/16-881-robust-system-design-summer-1998/725e6afee0f0698780362e394cd2dac7_l15_tol_des3.pdf)、[NIST 工程公差信息模型](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir6524.pdf)。这些参考不构成图纸国标/国军标合规认证。

### 区域定位

旧逻辑只检查 bbox 坐标是否合法，并未检查框外是否还有相连轮廓，因此偏小的模型框也会被接受。另有裁剪右/下边界向内取整的细小丢边风险。前端坐标映射的缩放回归未发现漂移。

修复内容：

- 定位提示明确要求整个视图、底部轮廓、伸出结构、中心线及所属标注。
- 在原页上进行局部连通图面内容补边；保留 `model_bbox`，输出修正 `bbox`、`bbox_status`、`bbox_basis`、`bbox_warning`、`needs_review`。
- 搜索窗口有界，不沿贯穿分隔线无限扩大到邻图。与原框不相交的邻图不会仅因附近有黑线被吸收。
- 裁剪左/上向下取整，右/下向上取整，保留边界像素。
- 增加“调整蓝框查看范围”和“框选文字修订范围”两个模式，并用颜色显示当前模式。临时蓝框只辅助查看，重新定位恢复自动范围；红框用于明确的人工文字修订。
- 蓝框模式不能提交文字修订。切换模式、取消拖动、重新定位会清除旧的文字选择和批量补丁输入，避免混用。

补边是图像启发式，不能保证全部语义范围：独立标注、断开的轮廓、远处内容、密集线条与错误区域归属仍可能不完整。搜索触及边界或无法独立跟踪时标为待核实；不把“坐标通过校验”称为“框选完整”。缺少 OpenCV 时保留粗定位并给出警告。

用户附件是带蓝框的局部截图。针对底部轮廓截断构造了同类回归图，并通过真实 `locate_regions` 调用链复现失败；未声称已获得附件的未标注整页原图，也未声称逐像素复测了原任务。

## 4. 你怎样审查

1. 正常重启本地服务，刷新浏览器。重新上传测试图，旧任务不会自动更新。
2. 先上传 `TC02_risk.png` 或同名 PDF。展开计算证据，核对 L=100±0.1、B=90±0.1、S=10±0.1，S 的计算范围9.8～10.2、允许范围9.9～10.1，ERR-01 应提示可能超差，并显示 B 为减环、L 为增环。
3. 上传 `TC01_within.png`：不应产生公差累积超差问题，证据面板仍有范围。上传 `TC05_missing_tolerance.png`：应显示依据不足，不能把 B=90 当作零公差并判定通过。
4. 定位视图，检查蓝框是否覆盖轮廓；可切换查看模式拖动扩大，检查它不会提交文字修订。再切换文字模式，只有重新框选的红框能作为修订范围。
5. 对照下面的所有开发样例，再看 `report.json` 和每例 JSON 中的真实模型原文。对于真实图纸，人工重点核对原文读数、所属分区、功能要求、端点对应；不能只看公式算得正确。
