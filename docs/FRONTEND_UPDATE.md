# 前端更新与验收

本次更新保留现有后端接口，调整主应用五个工作区的布局、说明与交互。数据集审查台是独立页面，本次没有重做其布局。

## 主要变化

- 统一深蓝导航、工程工作区、按钮、表格、状态提示和窄屏布局；增加使用指南、键盘焦点与跳过导航入口。
- 图纸入口明确“一次上传，生成 BOM 与图纸问题候选”，显示处理顺序；结果按零件清单、图纸问题、装配关系、修订副本组织。
- 上传区域显示文件名和大小，可拖放或使用 Enter、空格选择文件；任务处理中禁止再次提交及更换原文件。
- BOM 支持关键词筛选、可见行计数和未保存修改提醒。
- 文档和版本对比增加用途说明；高级 JSON 默认折叠；正式审核载入内容后自动展开。
- 设置页优先显示模型连接；企业字段配置与企业关联索引分别解释用途。
- 修复切换页面后的错误归属、慢请求重叠、上传输入事件递归，以及连续提取不同文档时导出链接仍指向旧任务的问题。

## 建议验收步骤

1. 启动项目服务，访问 http://127.0.0.1:8788/ ，按 Ctrl+F5 强制刷新。确认五个导航、顶部使用指南均可操作。
2. 在 BOM 页面选择“离线演示(Mock)”，选取一张测试图纸。检查文件名与大小显示，然后启动处理。演示数据是固定示例，仅验收操作流程。
3. 确认处理期间不能重复提交或更换图纸；结果出现后，通过顶部链接跳到各结果区。
4. 在 BOM 搜索框输入存在及不存在的件号，检查显示数量。清空搜索，修改名称或材料，确认出现未保存提示；保存成功后提示消失。
5. 打开“复核与历史”，载入当前 BOM，确认审核内容展开。保存编辑稿不代表正式批准，批准仍遵循原有身份和快照校验。
6. 在文档页面连续处理两个测试文件，检查每次导出都对应当前任务。
7. 切换系统设置，确认模型配置在前，并可区分企业导出字段配置与变更关联索引。无需更改现有密钥。
8. 缩窄窗口，确认导航可横向滚动、双列上传变为单列、宽表格在自身区域滚动；用 Tab 和 Enter 检查上传和指南操作。
