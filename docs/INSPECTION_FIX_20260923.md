# 审图漏检修正（2026-09-23）

## 触发案例

原始任务 `20260923135530-75599a` 识别了100、40和50，却没有发现同一线性尺寸链40+50不等于100。四条问题实际是日期、数量各重复一次；装配表的“0行关系待确认”将未识别关系数误写成待人工复核数。

## 改动

- 新增独立尺寸链观察：视觉模型引用尺寸数组下标，声明同页、同视图和连续端点；程序检查引用、拓扑连续性、单位和页码，再用Decimal计算总长与分段之和。未知几何关系、带公差尺寸、混合未知单位等不强行判错。
- 视觉审图必须返回ERR-01～ERR-10的检查状态和图面依据。缺少覆盖项会触发有界重试。覆盖表仍是模型声明，不能保证没有遗漏，界面明确提示人工复核。
- 重复报告按规则引用或保守的同字段/同行/同链证据合并，保留各来源原文与较高严重程度；前端可展开合并前证据。无法唯一匹配的报告保留独立。
- 装配状态分别显示未建立关系数和人工复核状态。根节点父项用量显示“不适用”。
- 标题栏展示必填空字段为“未填写”，并显示单位和页码等扩展字段；审图状态不再暗示完整通过。

## 验证

- 135项Python测试通过；JavaScript语法和上传/轮询专项测试通过。
- 真实Qwen复测使用原图和原始提取结果，不向模型提供expected.json。端点识别给出连续40、50分段及共同总长100，程序检出90≠100。
- 第一次复测保存在 `data/acceptance/axis_support_01/retest_20260923_141830/`。该轮结果暴露模型未返回关联编号的问题；后续增加确定性合并并以原始回复回放验证三个问题组。该文件保留为中间记录，不是最终部署结果。
- 随后通过网页重新上传原图，运行完整提取流程；新任务号为 `20260923142121-fc42f3`。完整结果保存在对应 `data/web_jobs/<任务号>/result.json`。
- 该完整任务已成功结束，网页实际显示3项：日期缺失、数量0与4冲突、尺寸链90与100冲突。四行BOM保持原值，装配父子用量1/1/4正确。已通过浏览器读取确认。
- 覆盖清单是模型自述，本次仍出现“材料均为45”等不准确表述；它不能作为独立真值或合规证明。已补充前端说明，核心问题判定以具体图面证据及算术结果为准。

原始任务备份位于上述retest目录的original_job.json；旧修订图片和审计文件仍在原任务目录。服务重启后旧任务不会自动回到内存任务列表，但磁盘记录保留。本次没有把历史任务重写成新算法结果。

## 使用与边界

新上传任务自动使用新逻辑。展开“审图覆盖与尺寸链证据”查看检查依据；确认设计意图后才能修改原标注。尺寸链连接关系仍由VLM识别，程序校验能够排除一部分无效链，不能替代工程师确认实际几何关系。当前加和检查只支持无公差普通线性长度，不声称完成复杂公差链或三维几何分析。
