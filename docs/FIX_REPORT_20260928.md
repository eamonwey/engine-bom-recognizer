## 修复结果

1. **PDF 比较漏检保护**：`engine_bom/changedetect.py` 在比较前逐页检查图片及矢量图形。包含这些内容时返回“比较不完整”、涉及页码和图面复核提示，不再以文字相同返回整份图纸无变化。纯文字 PDF 仍可比较。本次没有新增 OCR/视觉差异识别；含表格线、图框、标志等矢量或图片内容的 PDF 也会保守拦截。
2. **保存与导出一致性**：`engine_bom/webapp.py` 在落盘前验证数值与文本字段。数量等整数字段拒绝小数；拒绝布尔值、非数值文本和 NaN/Infinity，返回具体行号与字段；保留合法的 0 与 null。`static/app.js` 避免将非法输入经 JSON.stringify 隐式变成 null。
3. **可还原的人工修正记录**：每次成功保存记录 before/after、来源指纹、任务标识、操作者、时间和内容 hash。独立快照位于 `data/reviewed/edit_versions/`；日志包含快照路径和前后数据。文件分别原子替换；普通写入异常会回滚已经写入的文件，内存仅在写入成功后更新。损坏日志会阻止保存，不覆盖原记录。该机制不是跨文件的数据库事务，突然断电/进程强杀时仍需依据快照核查镜像文件；本次未承诺崩溃恢复。
4. **装配关系版本校验**：BOM 内容变化时 revision 增加，旧装配树失效；保存接口返回新 BOM，前端刷新装配表格和编辑器。层级提交携带 bom_revision，服务端拒绝过期版本。新任务的初始版本为 0；内容更改后，未携带版本的旧客户端提交同样会被拒绝。
