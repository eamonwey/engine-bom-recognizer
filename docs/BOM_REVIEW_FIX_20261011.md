# BOM 审查问题修复记录

日期：2026-10-11。

## 已修复

| 问题 | 修复后的行为 |
| --- | --- |
| 占位行和标准号疑点导致 AgentLoop 失败 | 保留原值及待核实标志；不会把这些人工核实提示送入模型重试；结构错误继续拒绝 |
| 企业 XLSX/CSV 导出原因列表 | 展示导出使用统一格式化，空列表显示空白，多条原因用分号连接；企业 JSON 保持结构化列表 |
| 保存后核实标志与数据不一致 | 保存时重新校验，更新行标志、原因和组件校验提示；清除旧规则产生的过时提示，保留其他检查信息 |
| 只更新派生标志使装配树失效 | 只有组件源字段变化才清除旧装配树和增加 BOM 版本 |
| 球标小数截断及 NaN/Inf 异常 | 两个检查路径共用整数解析；非法数字形成核实提示，不截断、不崩溃 |
| 缺省配置互相污染 | 没有 config.yaml 时同样返回独立的深拷贝 |
| 标准号带年份漏检 | 一致性查表忽略年份，支持常见破折号和全角写法；原标准号保留不改 |
| 独立审图漏用知识库 | BOM 与独立审图共用项目根路径锚定；两者继续使用公共审图配置 |
| 空结果锁定前端列 | 每次载入结果重新生成列，包含标准字段和当前结果字段 |
| 数字表示导致审核指纹不一致 | 数值相同的整数与整数浮点使用同一指纹；兼容旧快照，保留其历史审计哈希；实际内容变化仍拒绝 |
| 审核 GET 无身份校验 | 读取需要 API 令牌及已配置的三角色身份令牌；网页读取同步携带身份令牌 |
| 搜索隐藏正在编辑的行 | 编辑期间保持该行可见，失去焦点后重新过滤 |
| 徽标可能污染编辑值 | 徽标放在可编辑元素外部，保存后重新渲染核实标志 |
| AR/按需口径不一致 | 组件校验与 ERR-08 共用显式非数字数量豁免规则 |
| 非有限重量产生非法 JSON | 解析阶段拒绝 NaN/Inf，JSON 导出禁止非有限数值 |
| 长文本切片定位不精确 | 超长块切片使用独立 ID，并保存原块 ID、开始与结束偏移和对应切片原文 |

原报告的常规段落排序错误未复现；现有排序逻辑未因该项修改。未收录的标准号仍按保守策略交给人工核实。
