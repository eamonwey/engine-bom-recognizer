# 区域定位与审图可信度补充修复

## 行为

1. 蓝色区域定位框仅供查看，使用独立的 `insRegionBox`；红色手动框选才是文字修订范围。切换区域或原图页时清除旧修订框和旧批量JSON，避免误用此前的编辑。
2. 未重新手动框选时点击“生成文字修订副本”，前端阻止提交并提示框选。加载图片时禁用旧图片框选；异步旧图片响应不能覆盖最新页面。取消指针操作和零面积框也不保留修订范围。
3. 后端将覆盖清单分为“有计算/规则结果”和“仅模型观察”。后一类统一标为依据不足，不把“符合规范”“尺寸完整”等模型自述直接展示为结论。原始观察保留在 `model_observation` 和模型事件中供审计。
4. 已有具体检查结果也不代表该类别全部通过。例如检出了尺寸链矛盾，不表示所有尺寸、公差都已校验。
5. 前端脚本链接增加版本号 `20260923-2`。服务器原有no-store响应头保留。更新后需要重新加载页面，新上传任务使用新后端。

本次没有自动改写图纸尺寸或日期，也没有把模型观察升格为标准合规结论。覆盖清单保守显示依据不足是预期行为，完整工程审查仍需有效标准与人工复核。
